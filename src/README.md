# Paradise Nursery

Paradise Nursery is a React-based plant shopping application that allows users to browse different types of plants and add them to a shopping cart.

## Project Description

Paradise Nursery provides a simple and user-friendly online plant shopping experience. Users can explore different plant categories, view plant information, add plants to their shopping cart, update quantities, and remove items from the cart.

## Features

- Paradise Nursery landing page
- Get Started button
- About Us section
- Plant product listing
- Plant categories
- Add plants to cart
- Shopping cart
- Increase and decrease product quantity
- Remove products from cart
- Total item count
- Total cart price
- Responsive design

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- Vite
